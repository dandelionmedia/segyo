AI는 지금 어디까지 왔을까?

2026년의 AI는 글뿐 아니라 이미지·영상·소리를 만들고, 여러 단계를 이어서 작업하는 AI 에이전트 능력도 빠르게 발전하고 있습니다. 하지만 여전히 틀릴 수 있고, 현실 세계의 복잡한 일에는 한계가 있습니다.

📌 2026 Stanford AI Index는 최신 AI 모델의 과학·수학·멀티모달·코딩 능력과 에이전트 성능이 크게 향상됐지만, 특정 간단한 문제나 실제 환경에서는 여전히 실패가 남아 있는 ‘들쭉날쭉한 능력’을 강조합니다.

DAY 01 · 2026.09.10

첫째 날 · AI기초 + 나만의 책표지 디자인

📘
오늘의 작품: 내가 다시 해석한 책표지 1장
원래 표지의 디자인 원리를 발견하고 → 내 느낌을 더해 → 새로운 프롬프트로 재설계합니다.

실습 순서

1단계
책 표지 이미지 준비
내가 읽은 책을 검색해 표지를 저장합니다. 수업 분석용으로만 활용하고, 완성물을 공개할 때는 원본을 그대로 복제하지 않습니다.
2단계
표지 속 ‘디자인 비밀’ 발견하기
책 표지를 ChatGPT 또는 Gemini에 첨부하고, 비슷한 분위기를 만드는 데 필요한 디자인 요소와 프롬프트 구조를 분석합니다.
3단계
분석 프롬프트 저장
AI가 알려준 프롬프트를 메모장 또는 수업 문서에 저장합니다.
4단계
내 느낌으로 다시 설계
책을 읽고 느낀 감정·단어·장면·주인공의 모습을 넣어 ‘나만의 표지’ 프롬프트로 바꿉니다.
5단계
이미지 생성 + 비교
최종 프롬프트로 이미지를 만들고, 원래 표지와 무엇이 달라졌는지 이야기합니다.

2단계 실습 프롬프트 · 책표지 디자인 분석

여기서부터 복사 ➡
너는 전문 북디자이너이자 AI 이미지 생성 프롬프트 전문가야.

내가 지금 첨부한 이미지는 내가 읽은 책의 표지야.
이 이미지를 ‘그대로 복제’하는 것이 아니라, 이 책표지가 어떤 디자인 원리로 만들어졌는지 분석하고 비슷한 분위기의 새로운 표지를 만들 수 있는 이미지 생성 프롬프트 구조를 배우고 싶어.

다음 순서로 아주 구체적으로 분석해줘.

1. 전체 디자인 콘셉트와 분위기
2. 배경의 색상, 질감, 공간감
3. 가장 눈에 띄는 중심 소재 또는 인물
4. 인물이나 사물의 위치, 크기, 방향
5. 구도와 여백
6. 카메라 앵글 또는 시점
7. 빛의 방향, 밝기, 그림자
8. 대표 색상 3~5개와 색상 조합
9. 그림 스타일 또는 사진 스타일
10. 제목이 들어갈 위치와 글자 분위기
11. 독자가 이 표지를 봤을 때 느낄 감정
12. 비슷한 ‘디자인 원리와 분위기’를 가진 새로운 책표지를 만들 수 있는 한국어 이미지 생성 프롬프트

중요 조건:
- 원본 표지를 똑같이 복제하지 말고 디자인 특징만 분석해줘.
- 저자명, 출판사 로고, 기존 제목 등 원본의 고유한 글자와 로고는 그대로 따라 하지 말아줘.
- 마지막에 이미지 생성 AI에 바로 붙여넣을 수 있는 ‘최종 프롬프트’를 하나의 완성된 문장 묶음으로 작성해줘.
- 이미지 비율은 세로형 책표지에 어울리는 2:3 비율을 기본으로 해줘.
- 중학생도 이해할 수 있는 쉬운 말로 설명해줘.
💡 샘플 사용법
① 책표지 이미지를 먼저 첨부 → ② 위 프롬프트를 복사 → ③ 그대로 붙여넣기 → ④ AI가 분석한 결과 중 마지막 ‘최종 프롬프트’를 저장

4단계 실습 프롬프트 · 내 감정으로 책표지 재설계

여기서부터 복사 ➡
너는 청소년 독서 콘텐츠를 잘 이해하는 전문 북디자이너이자 이미지 생성 프롬프트 전문가야.

앞에서 분석한 책표지 프롬프트를 참고하되, 이제는 원본을 따라 만드는 것이 아니라 ‘내가 책을 읽고 느낀 생각’을 중심으로 완전히 새로운 책표지를 만들고 싶어.

[내가 입력할 정보]
- 책 제목: [여기에 입력]
- 책을 읽고 가장 크게 느낀 감정 3가지: [예: 설렘, 외로움, 용기]
- 책을 표현하는 핵심 단어 3~5개: [여기에 입력]
- 가장 기억에 남는 장면: [여기에 입력]
- 주인공의 모습/나이대/표정/옷차림: [여기에 입력]
- 표지에서 가장 강조하고 싶은 상징물: [여기에 입력]
- 내가 원하는 색감: [예: 푸른 밤, 따뜻한 노랑, 초록 숲]
- 내가 원하는 분위기: [예: 신비롭고 잔잔함]
- 꼭 넣고 싶은 제목 문구: [여기에 입력 / 없으면 '글자 없이']

요청:
1. 앞에서 분석한 표지의 장점 중 ‘구도, 여백, 색의 조화, 시선 집중 방식’만 참고해줘.
2. 원본 표지의 인물·그림·로고·폰트·고유한 디자인을 복제하지 말아줘.
3. 내가 적은 감정, 단어, 기억에 남는 장면을 중심으로 새로운 시각적 이야기를 만들어줘.
4. 이미지 속 인물은 책의 분위기를 표현하는 새로운 캐릭터로 설정해줘.
5. 책표지답게 제목 영역이 잘 보이고, 복잡하지 않으며, 작은 화면에서도 중심 이미지가 잘 보이게 해줘.
6. 이미지 비율은 세로 2:3.
7. 마지막 결과는 이미지 생성 AI에 바로 복사할 수 있는 ‘한국어 최종 이미지 생성 프롬프트’ 하나로 정리해줘.
8. 프롬프트에는 배경, 인물/사물, 구도, 색감, 조명, 감정, 표현 스타일, 카메라 시점, 텍스트 영역을 빠짐없이 넣어줘.
9. 한글 제목을 넣는 경우 “한글 철자를 정확하게 표현”하라는 조건도 추가해줘.
💡 샘플 입력
감정: 외로움·용기·희망 / 핵심단어: 밤길, 별빛, 우정 / 기억장면: 혼자 걷던 주인공이 친구를 만나는 순간 / 색감: 딥블루+따뜻한 노랑 / 분위기: 처음엔 쓸쓸하지만 끝에는 희망적
완성 이미지가 내 생각과 감정을 담고 있는가?
원본 표지를 그대로 베끼지 않고 새롭게 재해석했는가?

DAY 02 · 2026.10.08

둘째 날 · AI와 시를 만들고 시화 이미지 완성

📝
오늘의 작품: 나의 시 1편 + 시화 이미지 1장
AI에게 한 번에 “시 써줘”라고 하기보다, 내 경험과 감정을 먼저 꺼내고 함께 고쳐 봅니다.
1단계
AI와 시 만들기
내 경험·장면·감정을 입력하고 초안을 만든 뒤 대화하면서 표현을 다듬습니다.
2단계
시화 프롬프트 만들기
시화 이미지 생성 메이커 페이지 열기 ↗ → 내용을 입력해 이미지 프롬프트를 만듭니다.
3단계
시화 이미지 생성
완성된 프롬프트를 ChatGPT 또는 Gemini에 붙여넣고 이미지를 생성합니다.
4단계
시화 발표회
내 시의 한 구절과 이미지에 담긴 의미를 친구들에게 소개합니다.

1단계 실습 프롬프트 · 내 경험으로 시 만들기

여기서부터 복사 ➡
너는 중학생의 생각과 감정을 존중하면서 글쓰기를 도와주는 친절한 시 창작 코치야.
내가 직접 쓴 것처럼 내 경험과 내 말투가 살아 있는 시를 만들 수 있도록 도와줘.

먼저 나에게 아래 질문을 한 번에 보여줘.
내가 답하면 그 답을 바탕으로 시 초안을 만들어줘.

[질문]
1. 오늘 시로 쓰고 싶은 주제는 무엇이야?
2. 그 주제와 관련해 실제로 기억나는 장소는 어디야?
3. 그때 함께 있었던 사람 또는 떠오르는 사람은 누구야?
4. 가장 기억나는 장면 하나는?
5. 그 순간의 소리, 냄새, 날씨, 색깔 중 기억나는 것은?
6. 그때 내 기분을 단어 3개로 말하면?
7. 꼭 넣고 싶은 물건이나 상징 하나는?
8. 내가 직접 말하고 싶은 한 문장은?
9. 시의 분위기는 어떤 느낌이면 좋겠어? (따뜻함/유쾌함/쓸쓸함/신비로움/희망적 등)
10. 시 제목은 내가 정할까, 네가 5개를 추천할까?

내 답을 받은 다음에는:
- 10~16행 정도의 자유시 초안을 만들어줘.
- 너무 어려운 단어와 어른스러운 표현은 피하고 중학생이 실제로 쓸 법한 자연스러운 말로 써줘.
- 흔한 표현보다 내가 말한 구체적인 장면, 냄새, 소리, 색깔을 살려줘.
- 운율을 억지로 맞추지 말고 읽었을 때 자연스럽게 해줘.
- 내가 직접 적은 문장이 있다면 가능하면 중요한 위치에 살려줘.
- 시를 만든 뒤 ‘좋은 점 3가지’와 ‘더 내 글답게 바꿀 수 있는 부분 3가지’를 알려줘.
- 마지막에 “어떤 부분을 바꾸고 싶어?”라고 물어봐줘.
- 내가 수정 의견을 주면 전체 시를 다시 보여주되 바뀐 부분이 자연스럽게 이어지게 해줘.
💡 샘플 답변
주제: 할머니와 시장 / 장소: 평택 통복시장 / 장면: 할머니가 호떡을 반으로 나눠준 순간 / 소리: 사람들 목소리 / 냄새: 달콤한 호떡 / 감정: 따뜻함, 그리움, 행복 / 상징: 종이봉투

시를 더 잘 고치는 짧은 프롬프트

여기서부터 복사 ➡
지금 만든 시를 내 글처럼 더 자연스럽게 고쳐줘.
1) 너무 어려운 단어는 쉬운 말로,
2) 설명하는 문장은 장면이 보이게,
3) 뻔한 표현은 구체적인 감각 표현으로,
4) 가장 좋은 한 구절은 더 강하게,

[캐릭터 이미지 생성 필수 조건]

- 흰색 배경.

- 이미지 안에는 이름표, 로고, 설명 글자 등 불필요한 텍스트를 넣지 않는다.
- ChatGPT 또는 Google Gemini의 일반적인 이미지 생성 정책에 어긋나지 않도록 안전한 표현으로 작성한다.

- 선정적 표현, 노출, 혐오, 자해, 과도한 폭력, 피나 상처의 상세 묘사, 위험 행동을 멋있게 보이게 하는 표현은 넣지 않는다.
- 중학생 교육용 콘텐츠에 적합한 건강하고 밝은 장면으로 설계한다.
- 이미지 생성 모델이 한 번에 이해하기 쉽도록 ‘주인공 → 외형 → 표정 → 의상 → 배경 → 구도 → 조명 → 스타일 → 비율 → 제외 요소’ 순서로 프롬프트를 작성한다.
- 불필요하게 추상적인 표현은 줄이고 눈으로 확인할 수 있는 구체적인 시각 요소를 사용한다.
- 프롬프트 마지막에는 반드시 다음 제외 조건을 한 문장으로 넣는다: “실존 인물 복제 금지, 기존 캐릭터·로고·책표지 복제 금지, 선정성·과도한 폭력·혐오 표현 금지, 불필요한 글자·워터마크·서명 없음.”

C. 정확히 6개 장면의 스토리보드

[장면 이미지 생성 프롬프트 필수 조건]
- 모든 장면은 16:9 와이드 비율.
- 일관된 고품질 애니메이션 영화 스타일.

- 캐릭터가 필요 없는 장면에는 억지로 넣지 않아도 됨.
- 장면의 시간대, 장소, 배경, 인물 행동, 표정, 감정을 구체적으로 작성.
- 전문 사진/영화 촬영 기법을 장면마다 다양하게 활용:
  와이드샷, 미디엄샷, 클로즈업, 오버숄더샷, 로우앵글, 하이앵글, 아이레벨, 얕은 심도, 깊은 심도, 자연광, 역광, 골든아워, 부드러운 확산광 등에서 장면에 맞는 것을 선택.
- 카메라 구도와 피사체 위치도 구체적으로 설명.
- 시선이 어디로 가야 하는지 명확하게.
- 이미지 속 글자는 가능한 한 넣지 않는 것을 기본으로 함.
- 꼭 한글이 필요한 경우에는 “정확한 한글 철자, 오타 없는 한글 타이포그래피”라고 명시하고, 긴 문장 대신 짧은 단어만 사용.
- 기존 책표지, 출판사 로고, 삽화 등을 그대로 복제하지 말고 영상용으로 새롭게 시각화.
- 이미지 생성 프롬프트는 반드시 한국어로 작성.
- 각 장면의 이미지 프롬프트는 다른 설명과 섞이지 않게 별도의 복사 영역처럼 제공.
- ChatGPT 또는 Google Gemini의 일반적인 이미지 생성 정책에 어긋나지 않도록 교육용으로 안전한 장면과 표현만 사용한다.
- 실제 학생·교사·유명인 등 실존 인물의 얼굴을 그대로 복제하거나 닮게 만들지 않고, 등장인물은 새롭게 설계한 가상 캐릭터로 표현한다.
- 특정 유명 애니메이션·게임·영화 캐릭터, 유명 작가의 화풍, 기존 출판물 삽화와 너무 비슷하게 만들지 않는다.
- 책 속에 위험·폭력·공포 내용이 있더라도 피, 상처, 무기 사용의 상세 표현 대신 상징적이고 비폭력적인 연출로 바꿔 표현한다.
- 선정성, 노출, 혐오, 자해, 잔혹 묘사, 위험 행동 조장, 차별적 표현은 제외한다.
- 중학생이 보는 교육 콘텐츠에 맞는 표현 수위를 유지한다.
- 이미지 생성 모델이 한 번에 이해할 수 있도록 각 프롬프트를 다음 순서로 작성한다:
  ① 장면 핵심 ② 장소·시간대 ③ 인물/사물 ④ 행동·표정 ⑤ 구도·샷 ⑥ 조명·색감 ⑦ 애니메이션 스타일 ⑧ 16:9 ⑨ 일관성 조건 ⑩ 제외 요소.
- 장면마다 너무 많은 인물·소품·효과를 넣지 말고 핵심 피사체 1~3개를 중심으로 단순하고 명확하게 구성한다.
- 한 번에 이미지가 잘 생성되도록 서로 충돌하는 지시(예: 밤인데 강한 한낮 햇빛, 클로즈업인데 전신이 모두 보이게 등)는 사용하지 않는다.
- 프롬프트 마지막에는 반드시 다음 제외 조건을 넣는다: “실존 인물 복제 금지, 기존 캐릭터·로고·책표지·삽화 복제 금지, 선정성·과도한 폭력·혐오·자해 표현 금지, 불필요한 글자·워터마크·서명 없음.”

각 장면의 이미지 프롬프트 바로 앞에는 반드시 정확히:
“여기서부터 복사 ➡”
라고 적어줘.

[나레이션 작성 필수 조건]
- 각 장면당 약 2~4문장.
- 중학생이 직접 말해도 자연스러운 쉬운 한국어.
- 전체를 이어 읽었을 때 하나의 이야기처럼 연결.
- 책의 결말이나 큰 반전을 직접 말하지 않음.
- 사실을 꾸며내지 않음.
- 장면 번호를 나레이션 앞에 반드시 표시.

각 장면의 나레이션 앞에는:
“장면 1 나레이션”, “장면 2 나레이션”처럼 번호를 넣고,
그 아래에 “여기서부터 복사 ➡”를 적어줘.

━━━━━━━━━━━━━━━━━━━━
D. 나레이션 전체 복사용 대본
━━━━━━━━━━━━━━━━━━━━
6개 장면을 모두 만든 뒤 맨 마지막에,
장면 1~6의 나레이션만 순서대로 하나로 합쳐서
“전체 나레이션 한 번에 복사” 영역을 만들어줘.

형식:
전체 나레이션 한 번에 복사
여기서부터 복사 ➡
[장면 1~6 나레이션 전체]

━━━━━━━━━━━━━━━━━━━━
E. 마지막 점검표
━━━━━━━━━━━━━━━━━━━━
마지막에 아래를 체크해줘.
- [ ] 장면은 정확히 6개인가?
- [ ] 모든 장면이 16:9인가?
- [ ] 애니메이션 스타일이 일관적인가?
- [ ] 같은 캐릭터의 외형이 장면마다 일관적인가?
- [ ] 모든 이미지 프롬프트가 한국어인가?
- [ ] 각 프롬프트 앞에 ‘여기서부터 복사 ➡’가 있는가?
- [ ] 각 장면에 나레이션이 있는가?
- [ ] 스포일러를 과하게 말하지 않았는가?
- [ ] 책을 읽어보고 싶은 궁금증이 남는가?
- [ ] 내가 제공하지 않은 사실을 임의로 만들지 않았는가?\n- [ ] 정책상 안전하지 않은 표현을 제거했는가?\n- [ ] 기존 캐릭터·실존 인물·책표지를 그대로 복제하지 않았는가?\n- [ ] 이미지 생성 지시가 서로 충돌하지 않고 한 번에 이해하기 쉬운가?

━━━━━━━━━━━━━━━━━━━━
F. 이미지 생성 성공률을 높이는 최종 정리 규칙
━━━━━━━━━━━━━━━━━━━━
캐릭터와 6개 장면의 이미지 생성 프롬프트를 모두 만든 뒤, 각 프롬프트를 다시 한 번 점검해줘.

점검 기준:
1. 정책상 문제가 될 수 있는 실존 인물 복제, 유명 캐릭터 복제, 선정성, 잔혹한 폭력, 혐오, 자해 표현이 없는가?
2. 저작권이 있는 기존 책표지·로고·삽화를 그대로 따라 하라는 지시가 없는가?
3. 한 프롬프트 안의 장면, 인물 수, 행동, 카메라 지시가 서로 충돌하지 않는가?
4. 이미지에서 가장 중요한 피사체가 무엇인지 한눈에 이해되는가?
5. 캐릭터의 외모와 의상이 6개 장면 전체에서 유지될 수 있도록 동일한 핵심 묘사가 반복되는가?
6. 불필요한 글자 생성 요청을 최소화했는가?
7. 장면마다 장소, 시간대, 인물 행동, 표정, 카메라 샷, 조명, 색감, 스타일, 비율이 빠짐없이 들어 있는가?
8. 중학생 교육용 콘텐츠로 안전하고 자연스러운가?

문제가 있으면 스스로 안전하고 명확한 표현으로 수정한 뒤 최종 프롬프트만 출력해줘.
정책상 생성이 어려울 수 있는 장면은 거절을 유도하는 표현을 그대로 두지 말고, 교육 목적과 이야기의 의미를 유지하면서 ‘상징적 장면, 비폭력적 연출, 실루엣, 표정 중심, 사물 중심’ 등 안전한 대체 장면으로 바꿔줘.

중요:
결과를 생략하지 말고 A부터 F까지 전부 작성해줘.

AI SMART RULES

AI를 잘 쓰는 학생의 6가지 약속

① AI의 답을 그대로 믿지 않기

책 정보, 저자, 사실은 책과 믿을 수 있는 자료에서 다시 확인합니다.

② 내 생각을 먼저 넣기

AI에게 전부 맡기기보다 내가 느낀 감정·장면·이유를 먼저 입력합니다.

③ 개인정보 넣지 않기

주소, 전화번호, 비밀번호, 친구의 민감한 정보는 프롬프트에 입력하지 않습니다.

④ 저작권 존중하기

책표지나 삽화를 그대로 복제해 내 작품처럼 사용하지 않고, 수업에서는 분석 후 새롭게 재해석합니다.

⑤ 친구의 얼굴은 허락받기

친구 사진이나 목소리를 AI에 넣을 때는 반드시 본인의 동의를 받습니다.

⑥ 마지막 선택은 내가 하기

AI가 여러 아이디어를 주더라도 어떤 표현을 쓸지 결정하고 책임지는 사람은 나입니다.
